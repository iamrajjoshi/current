# Current Roadmap

Current is a native macOS daily stream Markdown editor. MVP 0 is deliberately narrow: one Daily stream, transparent daily Markdown files, fast native typing, paste-heavy capture, autosave, and recent-history scrolling.

## Phase 0: Capture Core

- Native AppKit-backed Markdown editor
- One Daily stream (`daily` on disk)
- Today plus recent timeline
- Transparent daily files
- Autosave and conflict handling
- Lazy history loading
- Jump to today, insert timestamp, reveal files

## Phase 1: Stream Power

- Multiple streams
- Stream switcher
- Rename and archive streams
- Collapsible days
- Calendar day picker
- Search across history
- Saved searches
- Import existing Markdown daily notes

## Phase 2: Daily Workflow

- Start-day template
- End-day review mode
- Mark day as reviewed
- Unchecked checkbox roll-forward
- Weekly review
- Export date range
- Print and PDF export
- Menu bar quick capture
- Global hotkey and floating capture window

## Phase 3: Organization

- Tags
- Wiki-links and backlinks
- Related notes sidebar
- Move selected text to another stream
- Manual extract to separate note
- Filter by incomplete checkboxes
- Lightweight dashboard with today, recent activity, and unresolved items

## Phase 4: Sources

- Apple Calendar
- Google Calendar
- Granola
- Notion
- Slack-aware paste and source handling
- Apple Reminders export
- Linear and Todoist export
- Obsidian-compatible export
- MCP server for local agents

## Phase 5: AI Review

- AI summarize current day
- AI extract action items
- AI group notes by meeting or topic
- AI suggest follow-ups
- AI create weekly summary
- AI answer questions over stream history
- User-approved diff and writeback only
- Bring-your-own API key and local model support where possible

## Phase 6: Cross-Device

- iPhone companion capture
- iPad editor
- Share extension
- Today widget
- File-based sync first
- CloudKit sync later
- Offline-first behavior
